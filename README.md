# Witch Survivor

Game survivor-like 2D (1300x700) buatan Python + Pygame. Semua serangan otomatis,
kamu fokus bergerak, menghindar, dan membangun build sihir terkuat.

## Fitur
- 20+ avatar penyihir, masing-masing dengan skill khusus
- 25+ sihir dengan sistem Evolusi, Kombo, dan Fusi
- Mode Normal & Mode Inflasi (bos akhir: Raja Inflasi)
- Boss geometri berirama, pedagang keliling, quest harian/mingguan
- Event Halloween 2026: Penebusan Jiwa di Desa Tembaga
- Tutorial interaktif
- Musik & efek suara dibuat prosedural, tanpa file audio
- Kontrol joystick virtual (HP) atau WASD/panah (PC)

## Menjalankan
pip install pygame
python witch_survivor.py

Di Pydroid 3: Pip, cari "pygame", install, lalu jalankan.
